# Scott Converse

Builder in Longmont, Colorado. Founder of [TinkerMill](https://tinkermill.org/) and [Longmont Public Media](https://longmontpublicmedia.org/).

I build **local-first, native-Windows open-source software** for civic transparency, community media, verifiable AI coding workflows, and makerspace fabrication.

---

### Civic & Municipal Infrastructure
- **[Townlight](https://github.com/townlight)** ([site](https://townlight.github.io/)) — Modular, local-first municipal operations suite (public records, meetings, ordinances, zoning, permits, station operations, and more).
- **[TownReporter](https://github.com/scottconverse/TownReporter)** — Self-hosted civic newsroom: public paper, editor desk, document reporting, and human-reviewed source verification.
- **[CivicCast](https://github.com/scottconverse/civiccast)** & **[civiccast-brief](https://github.com/scottconverse/civiccast-brief)** — Pure native-Windows PEG broadcast station-in-a-box (no WSL, no Docker) and meeting-video-to-cited-recap & two-host AI podcast pipeline.
- **[TownRecord](https://github.com/scottconverse/townrecord)** — Local-first civic portal watching city, county, and state meetings and public records with cited AI answers.

### Public Media & Accessibility
- **[Describer-Workbench](https://github.com/scottconverse/Describer-Workbench)** — Shared audio-description engine with a native Windows workbench, Python library, CLI, REST/OpenAPI, and MCP interfaces.
- **[TextFlowKit](https://github.com/scottconverse/textflowkit)** — Cross-platform media transcription toolkit (native AMD ROCm GPU support, no WSL) turning URLs or files into timestamped transcripts and subtitles.
- **[CuePorch](https://github.com/forkcommons/CuePorch)** *(via [Fork Commons](https://github.com/forkcommons))* — Video publishing for public media and the arts.

### AI Coding Workbench & Verification
- **[Rigwell](https://github.com/scottconverse/rigwell)** — Local coding workbench with persistent Workstreams, model choice, Git worktrees, and review.
- **[VerdictLite](https://github.com/scottconverse/verdictlite)** & **[Verdict](https://github.com/scottconverse/verdict)** — Evidence-first verification for AI coding agents (*"the agent writes claims, never verdicts"*).

### Local AI CAD, Research & Tools
- **[TinkerQuarry](https://github.com/scottconverse/TinkerQuarry)**, **[ScadMill](https://github.com/scottconverse/scadmill)** & **[tq-threads](https://github.com/scottconverse/tq-threads)** — Local-first AI CAD workflow, source-first OpenSCAD workbench, and clean-room printable OpenSCAD screw threads.
- **[Siftwing](https://github.com/scottconverse/siftwing)** & **[PatentForge](https://github.com/scottconverse/patentforge)** — Local research workspace for retained sources/PDFs and fully local patent analysis powered by Ollama + Gemma 4.
